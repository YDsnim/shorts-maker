# 숏츠 메이커 — 프로세스 흐름도

```
══════════════════════════════════════════════════════════════════════════════
                         전체 데이터 흐름 (지도)
══════════════════════════════════════════════════════════════════════════════

  ┌──────────────────────────────────────────────────────────────────────┐
  │                          [ 사용자 브라우저 ]                           │
  │                                                                      │
  │   ① 파일 선택                             ② YouTube URL 입력          │
  │     드래그&드롭 또는 클릭                    주소창에 붙여넣기            │
  └────────┬──────────────────────────────────────────┬─────────────────┘
           │                                          │
           │ POST /upload                             │ POST /fetch-youtube
           │ (동영상 파일을 서버로 전송)               │ (서버가 yt-dlp로 다운로드)
           │                                          │
           └──────────────────┬───────────────────────┘
                              │
                              ▼
                 ┌────────────────────────┐
                 │  uploads/{uuid}.확장자  │  ← 원본 임시 보관 공간
                 │  (예: a3f9c1d2.mp4)   │     파일명을 UUID로 저장하는 이유:
                 └────────────┬───────────┘     같은 이름 파일 충돌 방지
                              │
             ┌────────────────┴─────────────────┐
             │                                  │
             ▼                                  ▼
      ③ 자르기 적용                        ④ 대본 추출
      POST /process                       POST /transcribe
      (크롭 영역을 서버로 전송)            (음성 인식 요청)
             │                                  │
             │ ffmpeg crop 필터                 │ Whisper AI (small 모델)
             │ → 지정한 영역만 잘라냄            │ → 음성을 텍스트로 변환
             │                                  │   (한국어 특화 인식)
             │                                  │
             ▼                                  ▼
      output/                            output/
      {원본명}_crop_1.mp4                {원본명}_transcript_1.srt
      (예: 여름휴가_crop_1.mp4)          (예: 여름휴가_transcript_1.srt)
             │
             │ ※ 크롭 완료 직후
             │   원본도 output/ 으로 이동됨
             ▼
      output/{uuid}.확장자  ← 원본 보관 (대본 추출 등 재활용 가능)


  ┌─────────────────────────────────────────────────────────────────────┐
  │                          ⑤ 다운로드                                  │
  │                                                                     │
  │   GET /download/{filename}                                          │
  │   output/ 폴더에서 파일을 브라우저로 전송                              │
  │                                                                     │
  │   .mp4  →  완성된 크롭 영상                                          │
  │   .srt  →  SRT 형식의 자막/대본 파일                                 │
  └─────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────┐
  │                    ⑥ 자동 파일 정리 (TTL)                            │
  │                                                                     │
  │   요청이 들어올 때마다 → before_request 훅 → cleanup_old_files()    │
  │   단, 마지막 실행으로부터 1시간이 지난 경우에만 실제 삭제 수행         │
  │   (매 요청마다 삭제하지 않는 이유: 서버 성능 부담 방지)               │
  │                                                                     │
  │   삭제 대상                                                          │
  │   ├─ output/  → 생성된 지 1시간 이상 된 모든 파일                    │
  │   └─ uploads/ → 처리 실패 등으로 남아있는 임시 파일                  │
  └─────────────────────────────────────────────────────────────────────┘
```

```
══════════════════════════════════════════════════════════════════════════════
                        파일 구조와 각 파일의 역할
══════════════════════════════════════════════════════════════════════════════

  shorts-maker/
  │
  ├── app.py                      Flask 메인 앱
  │                               · 모든 HTTP 엔드포인트(API) 정의
  │                               · 파일명 생성, TTL 정리, Whisper 캐시 등
  │                                 보조 함수들도 여기에 모아둠
  │
  ├── config.py                   전역 설정값 모음
  │                               · 폴더 경로, 업로드 크기 제한
  │                               · 파일 보관 TTL (1시간)
  │                               · API 키 등 환경변수 읽기
  │
  ├── requirements.txt            Python 패키지 목록
  │                               · Flask, yt-dlp, openai-whisper 등
  │
  ├── modules/
  │   └── video_processor.py     ffmpeg 명령어 래퍼 모듈
  │                               · get_video_info() — 영상 해상도·길이 조회
  │                               · crop_custom()    — 지정 영역 크롭
  │                               · trim_video()     — 구간 자르기 (미래 활용)
  │                               · add_audio_to_video() — TTS 오디오 합성
  │
  ├── static/
  │   ├── css/style.css           전체 UI 스타일 (다크 테마)
  │   └── js/main.js              브라우저에서 실행되는 동작 전체
  │                               · 파일 업로드 / YouTube URL 가져오기
  │                               · 크롭 박스 드래그 UI (마우스·터치)
  │                               · 서버 API 호출 및 결과 처리
  │
  ├── templates/
  │   └── index.html              메인 HTML 페이지 (단일 페이지 앱)
  │
  ├── uploads/                    원본 영상 임시 저장 폴더
  │                               · 파일명: {uuid}.확장자 (충돌 방지)
  │                               · 크롭 완료 시 output/ 으로 이동
  │                               · 처리 실패 파일은 TTL 후 자동 삭제
  │
  └── output/                     처리 결과 보관 폴더
                                  · {원본명}_crop_N.mp4       — 크롭 결과
                                  · {원본명}_transcript_N.srt — SRT 대본
                                  · {uuid}.확장자              — 이동된 원본
                                  · 모든 파일 1시간 후 자동 삭제 (TTL)
```

```
══════════════════════════════════════════════════════════════════════════════
                           API 엔드포인트 일람
══════════════════════════════════════════════════════════════════════════════

  Method  경로                    역할
  ──────  ──────────────────────  ───────────────────────────────────────
  GET     /                       메인 페이지 렌더링 (index.html)
  GET     /uploads/{filename}     원본 영상 스트리밍 (크롭 미리보기용)
  POST    /upload                 영상 파일 업로드 → uploads/ 에 UUID 저장
  POST    /fetch-youtube          YouTube URL → yt-dlp 다운로드 → uploads/
  POST    /process                크롭 좌표 받아 ffmpeg 실행 → output/
  POST    /transcribe             Whisper STT 실행 → .srt 파일 → output/
  GET     /download/{filename}    output/ 파일을 브라우저로 다운로드 전송
```

```
══════════════════════════════════════════════════════════════════════════════
                        파일명 생성 규칙
══════════════════════════════════════════════════════════════════════════════

  서버 내부 식별용 (uploads/ 에 저장)
  └─ {uuid}.확장자                 예) a3f9c1d2ee4b5678.mp4
     └ 충돌 없이 유일한 이름 보장

  다운로드용 (output/ 에 저장)
  ├─ 크롭 영상   {원본명}_crop_{N}.mp4        예) 여름휴가_crop_1.mp4
  └─ SRT 대본   {원본명}_transcript_{N}.srt   예) 여름휴가_transcript_1.srt
     └ 같은 이름이 이미 있으면 N을 1씩 올려서 충돌 방지

  원본명 정리 규칙 (sanitize_base)
  ├─ OS 금지 문자 제거  < > : " / \\ | ? *
  ├─ 공백 → 언더스코어 _
  ├─ 한글·영문·숫자·_·- 는 그대로 유지
  └─ 최대 80자로 제한
```
