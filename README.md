# 숏츠 메이커

유튜브 숏츠 제작을 자동화하는 웹앱입니다.  
영상 업로드 → 영역 선택 → 변환 → 다운로드 흐름으로 동작합니다.

---

## 현재 기능

| 기능 | 설명 |
|------|------|
| **파일 업로드** | MP4·MOV·AVI·MKV·WebM, 최대 500MB, 드래그&드롭 |
| **YouTube 가져오기** | URL 붙여넣기 → yt-dlp로 자동 다운로드 |
| **영역 선택 (크롭)** | 드래그로 크롭 박스 조절, 9:16 비율 고정 옵션 |
| **배경 처리** | 크롭만 / 블러 배경 / 단색 배경 선택 |
| **YouTube 편집 흐름** | 다운로드 완료 후 영상 정보 확인 → "편집 시작" 버튼으로 자연스럽게 진입 |
| **서버 프리뷰** | 블러·단색 배경 선택 시 20%·50%·80% 구간 3장 동시 미리보기 |
| **실시간 진행률** | SSE 방식으로 변환 % 실시간 표시 |
| **대본 추출** | faster-whisper medium(GPU) → SRT 자막 파일 다운로드 |
| **모바일 지원** | 터치 핸들 50px 확대, 9:16 토글 즉시 적용 |

## 처음 설치 (최초 1회)

### 1. ffmpeg 설치
영상 처리에 필수입니다. 없으면 아무것도 동작하지 않습니다.

1. https://www.gyan.dev/ffmpeg/builds/ 에서 `ffmpeg-release-essentials.zip` 다운로드
2. 압축 해제 후 `bin` 폴더 경로를 Windows 환경변수 PATH에 추가
3. 확인: `ffmpeg -version`

### 2. Python 패키지 설치
```
pip install -r requirements.txt
```

### 3. 환경 점검
```
python setup_check.py
```
ffmpeg, Flask 등 필수 항목이 모두 OK인지 확인합니다.

## 파일 이름 형식

처리 결과 파일은 다음 형식으로 저장됩니다.

```
uploads/ (원본 — 임시 보관, 재작업 가능)
  20250611_143022_여름휴가.mp4        ← 일반 업로드
  20250611_143045_인터뷰_yt.mp4       ← YouTube 다운로드

output/ (변환 결과물만 저장)
  20250611_143030_여름휴가_crop_1.mp4
  20250611_143030_여름휴가_blur_1.mp4
  20250611_143030_여름휴가_color_1.mp4
  20250611_143030_여름휴가_transcript_1.srt
```

같은 이름이 겹칠 경우 `_2`, `_3` 식으로 카운터가 붙습니다.

---

## 파일 자동 삭제

`uploads/`와 `output/` 폴더 모두, **마지막 수정 시각으로부터 5분** 이 지난 파일은 자동으로 삭제됩니다.

- 삭제는 서버에 요청이 들어올 때 실행됩니다 (백그라운드 타이머가 아님)
- 보관 시간 변경: `config.py`의 `OUTPUT_TTL_SECONDS` 값 수정
- 중요한 결과물은 변환 직후 다운로드해두는 것을 권장합니다

## 자주 쓰는 명령어

```
# 서버 시작
python app.py

# 환경 점검
python setup_check.py

# 패키지 재설치
pip install -r requirements.txt

# ffmpeg 버전 확인
ffmpeg -version

# 포트 5000 사용 중인 프로세스 확인 (포트 충돌 시)
netstat -ano | findstr :5000
```

## 주의사항

- **ffmpeg 필수** — 없으면 영상 처리 전부 불가
- **인터넷 필요** — yt-dlp(유튜브 다운로드), Whisper 첫 실행 시
- **Whisper 첫 실행** — medium 모델 자동 다운로드 (약 1.5GB, 시간 소요) / NVIDIA GPU 필요
- **최대 업로드** — 500MB 제한 (`config.py`의 `MAX_CONTENT_LENGTH`에서 변경 가능)
